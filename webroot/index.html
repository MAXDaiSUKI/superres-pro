参数说明 / 注意事项

超分档：0 = 不超分（只插帧）；1 = 超分中；2 = 超分高。

插帧：1 = 开，0 = 关。对应 gpp_app_list 的 包名,超分,插帧。

全局支持（推荐开）——写 vendor.gpp.allgame.enable=1，Cube 会给任意游戏返回非 0 的 getGfrcCapByPkg，于是每个游戏里都能打开「超境画质」原版面板自己挑档位。关掉则只有系统出厂登记过的游戏（比如鸣潮、王者）才有面板。

档位：面板优先（默认）——模块只把游戏加进 gpp_app_list，超分/插帧交给游戏内的「超境画质」面板去调。面板只会对系统已登记支持的游戏出现（Cube 的 getGfrcCapByPkg 返回非 0）。

档位：强制写入——按下面选的档位写进 game_gfrc_mode，忽略面板选择。系统里 cap=0 的游戏强写通常也会被立刻回退，只在少数情况下有用。

面板调完档位后，系统会把该游戏记成 包名+超分档插帧gfrc（第三位必须为 1 才真插帧）；GameAssist 自己只会写 +010。

系统要求游戏原始分辨率小于 1080×2400，否则超分不生效。

「保存并应用」会重写名单、bind mount 覆盖 /system/etc/gpp_app_list 并重启 gppservice；正在运行的游戏需切一次后台再切回来。重启手机后由模块 overlay 自动恢复。

本模块只改 gpp_app_list，不动系统分区文件，卸载即还原。
